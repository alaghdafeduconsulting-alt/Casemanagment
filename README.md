# فضاء آفاق

مساحة عمل واحدة لجمعية آفاق — مركز خطوات، تجمع كل أدوات المتابعة التي أُعدّت سابقًا.

**النسخة على Google (للفريق):** خطوات التثبيت في [`google/SETUP.md`](google/SETUP.md). البيانات تُحفظ في Google Sheet يملكه مسؤول الجمعية، والدخول برمز الفريق.

**النسخة على Claude:** https://claude.ai/artifact/NVSsut2EnaRM2FH9efGDjL

## ماذا يوجد فيه

| القسم | ماذا تفعل فيه |
|---|---|
| **اليوم** | التنبيهات (علامات مهمة، متابعة شهرية متأخرة، مواعيد المراجعة) وآخر ما سجّله الفريق |
| **الأطفال** | ملف لكل طفل: البطاقة، التطور حسب المجالات، السجل الكامل، أهداف المشروع الفردي |
| **الاجتماع الشهري** | جدول أعمال يُبنى تلقائيًا: الإحالات حسب الأخصائي، العلامات المهمة، الأطفال بدون متابعة |
| **التخطيط السنوي** | أعمال الموسم (شتنبر – غشت) حسب المحاور، الجدول الزمني، المنجز مقابل المبرمج، ونص الخطة وتقرير الإنجاز |
| **الأنشطة** | لقاءات الآباء، الورشات، التكوين، الشراكات، مرتبطة بالخطة السنوية، مع حصيلة سنوية جاهزة للتقارير |
| **الأدوات** | عرض لقاء الآباء «سلوك طفلي يتعبني» مع ملاحظات المنشّط، مطبوعات اللقاء، وروابط سريعة للنماذج |

## النماذج داخل ملف الطفل

- ملاحظة المربي (أولى أو شهرية)
- التقييم الأكاديمي (مستويات التلقين)
- الجاهزية للمدرسة
- رد الأخصائي على المربي
- شبكة رصد التعثرات النمائية
- التقييم النفسي الشامل (نسخة التوحد ونسخة مرنة)
- متابعة المرافق اليومية
- ملاحظة جلسة

وفي ملف كل طفل تبويب **الإدماج المدرسي**: التكييفات، الملف الإداري، وطلب التكييف بالعربية والفرنسية.

كل نموذج يعطي نتيجة ونصًا جاهزًا للنسخ أو التنزيل، ويقارن مع التسجيل السابق.

## ملاحظات

- البيانات مشتركة بين كل من يملك الوصول إلى الرابط داخل المؤسسة. شارك الرابط مع الفريق من زر «Share» في الصفحة.
- السرية: رمز واسم أول فقط، بدون أسماء كاملة أو تفاصيل تشخيص.
- الكود كله في ملف `index.html` (نفس الملف يعمل على Google وعلى Claude)، والحفظ على Google في `google/Code.gs`.
