# فضاء آفاق

مساحة عمل واحدة لجمعية آفاق — مركز خطوات، تجمع كل أدوات المتابعة التي أُعدّت سابقًا.

**رابط التطبيق:** https://claude.ai/artifact/NVSsut2EnaRM2FH9efGDjL

## ماذا يوجد فيه

| القسم | ماذا تفعل فيه |
|---|---|
| **اليوم** | التنبيهات (علامات مهمة، متابعة شهرية متأخرة، مواعيد المراجعة) وآخر ما سجّله الفريق |
| **الأطفال** | ملف لكل طفل: البطاقة، التطور حسب المجالات، السجل الكامل، أهداف المشروع الفردي |
| **الاجتماع الشهري** | جدول أعمال يُبنى تلقائيًا: الإحالات حسب الأخصائي، العلامات المهمة، الأطفال بدون متابعة |
| **الأنشطة** | لقاءات الآباء، الورشات، التكوين، الشراكات، مع حصيلة سنوية جاهزة للتقارير |
| **المراجع** | روابط الوثائق والعروض السابقة |

## النماذج داخل ملف الطفل

- ملاحظة المربي (أولى أو شهرية)
- التقييم الأكاديمي (مستويات التلقين)
- الجاهزية للمدرسة
- رد الأخصائي على المربي
- شبكة رصد التعثرات النمائية
- ملاحظة جلسة

كل نموذج يعطي نتيجة ونصًا جاهزًا للنسخ أو التنزيل، ويقارن مع التسجيل السابق.

## ملاحظات

- البيانات مشتركة بين كل من يملك الوصول إلى الرابط داخل المؤسسة. شارك الرابط مع الفريق من زر «Share» في الصفحة.
- السرية: رمز واسم أول فقط، بدون أسماء كاملة أو تفاصيل تشخيص.
- الكود كله في ملف `index.html`.
